# READMEの紹介メディア

- `workflow.gif`：実際のビュワーで、入力画像・生成モデル・分割マーカー・関節操作を撮影したループGIF。
- `workflow.png`：同じ操作例を4工程で並べた静止画。

プテラノドンはユーザー提供の入力画像から生成した操作例です。元画像や3Dモデルのデータは同梱していません。画面キャプチャへの収録によって、元の素材やAIモデルの利用条件が変更されるものではありません。

生成・加工済みのデータで工程を切り替えて撮影し、待ち時間を省略しています。可動域の場面では実際のキー操作で関節を動かしています。紹介用の見出しを追加し、モデル名と個人の保存ポーズ一覧を非表示にしています。形状の描き直しはしていません。

最後の画面はBambu Studioへの引き渡しを案内するもので、スライスや実機印刷の記録ではありません。
