# 高さを切り下げたソケットの嵌め合い確認（1.2.7）

1.2.6で半周に残っていた外縁の角を修正し、全周R1へ統一。球面・入口径・高さの設定は維持し、全試験片の対称性も検査します。

強いスナップ固定ではなく、手で取り外せることを優先した試作です。
8か所の受けの外形高さも全周で切り下げ、開口端を中心から1.5 mmにしています。
ソケット単体は少なくとも30°を目標に検査します。1.2.5の内側だけの加工とは異なります。
実物で「適度な硬さ」になるか、自重で外れないかはまだ未確認です。

現時点で確認できるのはCAD上の寸法・干渉・抜け止め形状です。
実物のガタつき、挿入力、抜ける力、摩耗はまだ測定していません。

## 今回の寸法

- ボール：6.0 mm（変更なし）
- 球面の受け：6.6 mm（変更なし）
- 直径差：0.6 mm、片側の公称隙間：0.3 mm
- 加工前の入口設定：5.8 mm。高さ加工後の公称0.6 mm版は約5.899 mm（断面サンプル測定）。
- 本体肉厚：2.0 mm、丸い縁の半径：1.0 mm
- 中心から前方の張り出し：約2.81 → 1.50 mm。外側の切り口はR1で丸めます。

入口がボールより約0.101 mm小さいため、CAD上は小さな抜け止めが残ります。
保持は前版より弱くなる可能性があります。印刷誤差・摩耗・材料で抜けやすさが変わります。
CADでは、着座状態は干渉せず、抜ける途中で縁に当たることを複数の位置で確認します。
これは「何Nで抜けるか」や「絶対に落ちない」の証明ではありません。
公称0.3 mmの片側隙間は残るため、ガタがないとも判断できません。

## 試験片

`build/print/starter_fit_kit.3mf` に、新形状の受け3種類と6 mmボールを配置しています。
1個・2個・3個の点が、それぞれ直径差0.4・0.6・0.8 mmです。
加工前の入口はすべて5.8 mmですが、高さ加工後の最小径は約5.888／5.899／5.911 mmです。
したがって、最終的な保持形状も異なります。1.2.5以前の旧試験片では今回の着脱性を評価できません。

実際に使うプリンタ・材料・向き・積層条件で試してください。

1. 現在の設定である2個の点（0.6 mm）から、無理な力をかけずに着座を確認。
2. 白化、ひび、層の剥がれ、完全に入らない状態があれば使用を中止。
3. 指先で軽く押し引きし、並進のガタと回転の抵抗を確認。
4. 抜け落ちても危険のない場所で、自重で外れないか、通常の関節操作で外れないか確認。
5. 挿抜と回転を繰り返し、抵抗低下や割れを確認。回数と変化を記録。
6. 0.6 mmでガタが大きければ0.4 mmを比較。0.4 mmで無理に押し込まないでください。

必要な保持力は脚・頭・尾の重量と使い方で変わります。
試験片だけでなく、最終部品と同じ向きで印刷した接続部でも確認が必要です。
結果が出るまでは、製品側の0.6 mm設定を自動的には変更しません。

CAEは標準骨とボール軸などの線形静解析です。
今回の受けのスナップ接触、弾性開き、疲労寿命を解析したものではありません。
取り外せる小部品を含む試作品であり、子ども向けの安全認証品ではありません。
