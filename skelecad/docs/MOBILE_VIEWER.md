# スマホ用ビュワー

> 現行版（2.0.0）はモデル選択・1本指の回転・2本指の拡大縮小・全体表示のみです。
> 以下は削除済みの編集版についての過去の記録です。現行画面には編集パネルはありません。

同じURLをスマホで開くと専用レイアウトへ切り替わります。
画面幅760px以下、または幅960px以下かつ高さ500px以下の横向き画面が対象です。
PC側の配置は従来どおりです。

- 上の「モデル」でモデル選択を開き、「中央へ」で表示中心だけ戻します（向き・ズームは保持）。
- 下の「①切断」「②ジョイント」で工程を切り替えます。
- 「操作を開く」で対象部位・パーツ・各編集操作を表示します。
  操作欄はスクロールでき、閉じるとモデル領域が広がります。
- モデル画面を2本指で広げる／つまむと拡大・縮小できます。
- 切断工程では1本指ドラッグで視点回転。ジョイント工程ではパーツの
  ドラッグが可動操作、背景ドラッグが視点回転です。
- 「盛る」「削る」を選ぶと操作欄を閉じて描画領域を確保します。
  選択中の操作名を下部に表示します。終了するには操作欄を開き、同じボタンを再度押します。
- ジョイント工程の「戻す」は盛る／削るのUndoです。ジョイント移動のUndoではありません。
- 切断工程の「＋ 新規の切り取り」で指描きできます。新規作成時は操作欄が閉じます。
  一覧で線を選ぶと編集、再度同じ線を押すと編集終了。視点のジャンプはしません。
  線はモデル表面に付き、回転しても残ります。背景には描けません。
  「戻す」は筆跡追加・描き直し・削除を取り消します。線は端末のブラウザ内に保存。
  「描いた線で分割」で、開いた線からでも切断面を作ります。描いた線はそのまま表示し、裏側・内部へ切断面を延長します。
  編集中は単色、分割後だけパーツを色分けします。対応する切断面を閉じ、青緑の削りしろを追加します。
  分割後はパーツを選び「削りしろを削る」「盛る」で調整。「戻す」で取り消せます。
  新規の線や線の選び直しでは分割を保持し、表示中のパーツをさらに切れます。
  「② ジョイント」で現在のパーツからソケット側・ボール側を選択。工程を往復しても状態を保持します。
  分割・そのパーツの造形は「分割 保存済み」後なら再読み込みで復元します。
  ジョイントの取付位置・姿勢とUndo履歴は未保存です。印刷用出力は未対応です。
  保存はその端末・ブラウザ・接続先ごとです（PCとスマホ、localhostとTailscaleで共有されません）。

モデル用の画面はヘッダーと操作欄の間に配置し、操作欄の開閉時には大きさを変えます。
軸と選択マーカーも画面の位置に合わせて表示します。ノッチ・ホームバーの安全領域に対応。
スマホ用の別URLや追加インストールは不要です。

ピンチの倍率・上下限・指を離した後の誤操作防止、画面オフセットを含めた
マーカー位置を自動テストに追加しています。実機のSafari/Chromeによる確認は別途必要です。
ブラウザの画面サイズを320×568、390×844、844×390に切り替え、
横方向のはみ出しがないこと、開いた操作欄とモデル画面が重ならないことを確認済みです。
390×844の閉じた状態ではモデル画面の高さは678pxです。
メニューの排他開閉と、盛る／削る選択時の操作欄の自動折りたたみも確認しました。
今回の変更はレイアウトと入力処理のみで、分割モデル・材料・CAD/STL・解析条件は変更しません。
