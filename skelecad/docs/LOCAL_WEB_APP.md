# ローカルWebアプリの使い方

## 開く場所

- このPC: http://127.0.0.1:8765/viewer/
- Tailscale経由: https://YOUR-DEVICE.YOUR-TAILNET.ts.net/3dviewer/

ホスト名だけの https://YOUR-DEVICE.YOUR-TAILNET.ts.net/ と、末尾の `/` がない
`/3dviewer` からも開けます。同じホストの入口 `/` もビュワーへ接続します。

Tailscale側のアクセス権がある接続済み端末で開いてください。
このPCが起動し、スリープせず、ビュワーのサーバーが動いている必要があります。
入口にアクセスするとビュワーへ転送され、フォルダ一覧は表示しません。

## 関節を動かして衝突を確認

「新規モデル：ジョイント加工済み」は、パーツを直接つかんで動かせます。
色分けは常時オンです。凡例や関節操作カードは出さず、モデルを全面に表示します。

- パーツをドラッグすると、その関節が動きます。脚を動かすと足先も追従します。
- 背景や胴体をドラッグすると視点が回ります。Alt＋ドラッグでも視点を回せます。
- Shift＋ドラッグでねじり、矢印キーで選択した関節を微調整できます。
- ドラッグ中も衝突を判定し、食い込み箇所を赤い点で表示します。
  衝突したときだけ、画面上部に衝突しているパーツ名を表示します。
  赤い点は裏側のものも透かして表示します。
- Homeで選択した関節、Escで全体の姿勢を戻せます。

表面の点を調べる近似判定なので、細かな干渉を見逃す場合があります。
衝突表示が出なくても、実物の可動域や組付けを保証するものではありません。
±60°は画面上の操作範囲です。姿勢を動かしても印刷データは変更されません。

## PC再起動後の起動

従来の `0_3Dモデルをぐりぐり確認.lnk` で起動できます。
通常は8765を使い、使用中の場合は空きポートを探します。
起動時に表示されたURLを使ってください。ログイン時の自動起動は設定していません。

設定確認も含めて起動する場合は、skelecadフォルダで次を実行します。

```powershell
.\tools\open_3d_viewer.ps1 -Tailscale
```

PC側でブラウザを開かずに起動する場合:

```powershell
.\tools\open_3d_viewer.ps1 -Tailscale -NoBrowser
```

既存の `/3dviewer` 接続先が異なる場合は上書きせずエラーにします。
入口 `/` が別用途に使われている場合も上書きしません。
別用途のTailscale Serve設定は変更しません。

## 公開範囲と保存

サーバーはPC内の127.0.0.1で待ち受け、Tailscale Serve経由で利用します。
インターネット一般公開用のFunnelは有効にしません。
画面、指定モデル、モデル設定のみ配信し、ブラウザプロファイルや
その他のプロジェクトファイル、フォルダ一覧は配信しません。

保存した姿勢スナップショットは同じブラウザのlocalStorageに残ります。
端末間では同期しません。未保存の操作は再読み込みで失われます。
画像ジョブ・分割指定・加工履歴はサーバーの`build/workflows/`に保存されます。
画像生成・加工・印刷APIはローカル接続専用で、Tailscale経由では実行できません。

サーバーログは `.runtime/viewer.stdout.log` と `.runtime/viewer.stderr.log` に出ます。
