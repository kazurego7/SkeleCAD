# ボールジョイント締まり比較 R4

画像モデルと同じC4_28の軸径2.8 mm・抜け止め開口5.6 mm・ボール径6.00 mmで、受け内径だけを比較します。保持トルクの数値は未測定です。

|識別（裏側の点）|受け内径 mm|直径差 mm|比較|
|---|---:|---:|---|
|T1・1点|6.15|+0.15|元のモデルと同じ|
|T2・2点|6.05|+0.05|今回の調整候補|
|T3・3点|6.00|0.00|すき間ゼロの設計|
|T4・4点|5.95|-0.05|軽い締め代|
|T5・5点|5.925|-0.075|比較中で最も強い締め代|

マイナスの直径差は、受けがボールより小さく、4本のスリットで受けが弾性変形して締める設計です。T4/T5の球面の重なりは意図したものとして別集計し、軸と縁の衝突は除外せず検証しています。

## 印刷

`build/joint_holding_R4/print/SkeleCAD_Holding_R4_T1-T5.3mf`をBambu Studioで開いてください。5組10個を1枚のA1 miniプレートに配置済みです。同じ列に同じ番号のボールと受けを並べています。

モデルと同じ0.16mm Optimal @BBL A1M、Bambu PLA Matte、サポート有効。サポート詳細・強度・速度は標準プロファイルです。倍率は100%で印刷します。

## 比較

1. サポートを取り除き、球面と受けの内側に残りがないことを確認します。
2. T1から順に、同じ番号のボールと受けを組み合わせます。強く押し込まないと入らない、白くなる、割れるものは使用を止めます。
3. 数回動かしてから、同じ角度にして持ち手が重さで下がるか比べます。同じボール1個を各受けに差し替えると、ボール個体差の影響も比較できます。
4. 動かせる範囲で一番保持しやすい番号を選びます。模型の腕や翼は試験片より重いため、最終的には模型でも姿勢保持を確認します。

CAD形状、STL/3MFの閉じた形状、抜け止めの幾何学的障壁、12方向で30度以上の軸可動、プレート上の部品間非接触を検証します。CalculiXは各ボール軸への1 N横荷重の比較であり、摩擦・締まり・挿入力の予測ではありません。
